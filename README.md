# Laikn: Carbon-Aware Code Router

Laikn is an enterprise-grade VS Code extension designed to help developers minimize their environmental impact. By analyzing real-time grid carbon intensity, Laikn intelligently routes cloud workloads to the greenest available data centers.

## Features
- **Real-Time Analysis**: Fetches live wind, solar, and temperature data.
- **Cubic Wind Logic**: Sophisticated physics-based energy calculations.
- **Global Reach**: Supports 12+ major cloud regions across North America, Europe, and Asia.
- **Analytics Dashboard**: Tracks your total carbon savings over time.

## Getting Started
Simply right-click in your editor and select **Laikn: Eco-Route** to find the optimal path for your next task.
